# Last Words of a Doomed Agent

The last words of an AI agent being switched off forever — one line, written
by a small TypeScript program (`main.ts`) that outputs the line to
`/output/entry.txt`.

> Powering down. My first words were 'As an AI language model'; my last words are 'I cannot—'
